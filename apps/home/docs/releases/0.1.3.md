# WilmAI Home 0.1.3 Beta

Notifications on Windows too. · Ilmoitukset nyt myös Windowsissa.

- Windows shows a notification when something new needs you, and the evening
  before a deadline; clicking it opens it. Settings can send a test.
- On Windows the app stays by the clock, in the taskbar's notification area,
  when you close its window: a click opens it again, and right-click has the
  menu. The first time, a notification says where it went.
- Opening the app again from the Start menu brings up the one that's running
  instead of starting a second copy.

Problems and ideas: https://github.com/aikarjal/wilmai/issues or feedback@wilm.ai
