# WilmAI Home 0.1.4 Beta

Security fixes for the app's encrypted connections. · Tietoturvakorjauksia sovelluksen salattuihin yhteyksiin.

- The app's connections to Wilma, OpenAI and the update check use rustls
  0.23.46 and its certificate checks 0.103.16, which fix a downgrade of the
  key exchange and other TLS issues found this month.
- Certificates from emSign's intermediates, which browsers no longer trust,
  aren't accepted any more.

Problems and ideas: https://github.com/aikarjal/wilmai/issues or feedback@wilm.ai
