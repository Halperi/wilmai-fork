# WilmAI Home 0.1.1 Beta

A message you wrote to a teacher no longer shows up as needing you. · Opettajalle itse kirjoittamasi viesti ei enää näy sinua odottavana.

- When a teacher answers a message you (or the other guardian) wrote, the
  thread shows up in the inbox. The AI could read your own request to the
  teacher as a step for you; messages your family wrote are now never "needs
  you", and their dates still reach the calendar.
- This is the first version that arrives inside the app: choose Download update,
  then Install and restart.

Problems and ideas: https://github.com/aikarjal/wilmai/issues
