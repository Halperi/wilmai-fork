# WilmAI Home 0.1.2 Beta

Signing in again is one click: the app remembers your Wilma password on this computer. · Uudelleen kirjautuminen on yksi klikkaus: sovellus muistaa Wilma-salasanasi tällä koneella.

- When Wilma ends the session, the sign-in page offers Sign in as … with the
  remembered password. On a shared computer, untick Remember on this computer
  when signing in; Settings can forget it, and signing out does too.
- Today shows the notes from the last three school days.
- A message thread reads oldest first, with the newest marked and long earlier
  messages folded, and shows its first message's own time.
- The version is in the menu's corner, with whether it's up to date; it opens
  Settings' Updates.
- Calendar: dismissing an event two messages mention now sticks, and adding one
  is no longer lost.

Problems and ideas: https://github.com/aikarjal/wilmai/issues or feedback@wilm.ai
